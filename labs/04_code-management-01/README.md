# Part 1: software licenses

Part 1 of this lab is a short [multiple-choice questionnaire on software licenses ([questionnaire-on-licenses.md](./questionnaire-on-licenses.md)). Select the correct answer(s) by adding a lower-case x in the corresponding boxes.

# Part 2: introduction to code modularity

This part is intended to demonstrate that, when a program is built in a modular way, it is possible to modify it without having to read and know the entire code.

We provide a terminal-based viewer for NetCDF files ([ncnc.py](./ncnc.py)). This programme is missing a functionality, and you will have to add it.
